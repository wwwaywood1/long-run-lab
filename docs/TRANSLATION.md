# 翻译规范（中 → 英）

适用于 `i18n/source/*.json`。译者只填 `en` 和 `note` 两个字段，其他字段不要改。

## 1. 读者与语气
- 读者是没有数学背景的普通人。用短句、主动语态、第二人称 you。
- 中文原文刻意留白、节奏短促，英文也要短。标题尽量不超过中文的 1.3 倍长度。
- 研究层（Research-*.json）面向专业读者，可以用术语，但仍要清楚。
- 语气：冷静、不说教、不恐吓。不要加原文没有的感叹号和形容词。

## 2. 硬性规则
1. **数字一个都不能改。** 百分比、倍数、局数、金额保持原值；只调整写法（`1,000`、`5.26%`、`1 in 17,721,088`）。可以调整的写法包括：万 / 亿 换算（`1,500 万` → `15 million`）、中文数字（`第一部分` → `PART 1`）、月份名（`2025 年 9 月` → `September 2025`）。
2. **占位符原样保留**：`{{rounds}}`、`{{itemText}}` 等不翻译、不改顺序以外的任何字符；英文语序需要时可以移动位置。
3. **换行标记** `<br>` 保留；英文可以按意群重新断行，但数量相近。
4. **术语以 `i18n/glossary.csv` 为准**，同一术语全站一致。表里没有的新术语，在 `note` 里写 `NEW TERM:` 提出来。
5. **金额**：数值都不变，分两类页面。
   - 赌场桌游页和章节页：金额是假设的赌注，英文用美元写法（`10 元` → `$10`），格式跟 `src/i18n/site.ts` 的 `money()`。
   - 用中国真实价格的页面：Lottery（双色球 2 元一注）、Scratch（10 元一张）、Gacha（648 元档）。英文版也用人民币，连页面里的模拟也一样。正文写 `yuan`（`2 yuan a bet`），票面这类窄位置写 `¥`（`¥100K`）。不要换成美元，也不要自己换算汇率：同样的数字写成美元就成了错的事实。
   - 所有页面里中国的真实统计（彩票销量、公益金）一律写 `yuan`。`亿` = hundred million，`5,756 亿元` → `575.6 billion yuan`。
6. **中国语境**：双色球、竞彩、刮刮乐、杀猪盘、文市发〔2016〕32 号等，第一次出现时用括号补一句背景，例如 `Double Color Ball (China Welfare Lottery)`。法规名用英文意译，并在 `note` 里保留中文原名。
7. **动态句子**（`kind: "script"`）：原文常被代码拆成碎片（如 `'本局：赢 ' + n + ' 桌 · 输 '…`）。请看 `context` 里的整行代码，在**第一个碎片**的 `note` 里写出完整英文模板，用 `{w}`、`{l}` 等标出变量，例如：`This round: {w} won · {l} lost · {t} triples · {delta}`。其余碎片的 `en` 可以留空。
8. **求助资源**（Ending.json）：热线电话不要直译。英文版需要换成英美等地的资源，在 `note` 里写 `LOCALIZE` 并给出建议（例如美国 1-800-GAMBLER，英国 GamCare），由核实环节确认。
9. **站名**：中文“概率的游戏”，英文 Long Run Lab，两者不互译。副标题：庄家从不掷“骰子” → The house doesn't play dice.

## 3. 交付
- 输出与输入结构完全相同的合法 JSON（UTF-8，缩进 2 空格）。
- 每批交付附一张表：新术语、拿不准的句子（id + 原因）。
- 交付顺序与移植顺序一致：先 `common.json` 和赌场游戏页，再章节页，最后研究层。
