# G9 足球竞猜：手选赔率、串关与真实概率

新增 `/zh/casino/sports/` 与 `/en/casino/sports/`。单单可手选 Home / Draw / Away、押热门和查看真实概率；开赛后逐场显示比分，全部比赛揭晓才结算整单。支持同时下 1 / 10 / 100 单、1 / 2 / 4 / 8 场串关、10 / 100 / 1,000 注额、自动押、快进 100 轮和重来。

基于 G8 完整交付版继续实现。赌场大厅加入足球竞猜，G8 的下一桌链接已可达。本文件可直接用于 PR，尚未创建远程 PR。

## 行为与实现

- `Sports.tsx` / `Sports.css` 按设计稿实现模拟、公益说明、赔率隐含概率揭晓、串关返还图和“懂球能赢吗”段落。复用六个共享组件：分段控件、盈亏头、实物换算、盈亏曲线、百单方阵、全黑揭晓段。
- 首次挂载后由引擎创建虚构比赛，避免服务端和客户端分别随机生成导致 hydration 不一致。手选时未选齐不能开赛；支持 Enter / Space；开赛后锁定投注、串关及选择按钮。真实概率开关可以随时查看或关闭，不改变生成的比赛。
- 单单在 250ms 后揭晓第一场，之后每 380ms 一场，最后再间隔一次才结算。已揭晓场次显示比分、实际结果的 ✓，选错显示 ×；未揭晓比分和实际结果不出现在 DOM / 无障碍名称中。十单/百单在 800ms 后统一揭晓。
- 多单、自动和快进都调用原引擎选热门。十单显示命中场数、赔率和单单净额；百单同时用 + / − 和颜色表示全中或至少错一场，读屏名称包括结果与金额。
- 自动停止取消下一轮，正在进行的一轮仍结算。重来和卸载清理所有揭晓、结算与自动计时器；自动暂停期间修改人数、串关和注额，下一轮读取最新配置。手动操作与快进会替换自动等待计时器，不留下重复轮次。
- 下一轮沿用设计稿的两步行为：第一次按“下一轮”创建待选比赛，选齐后再“开赛”；自动模式会直接押热门并开赛。快进始终另外生成 100 轮，按当前单数累计 100 / 1,000 / 10,000 单。
- **已结算结果保留当时注额。** 在结果页切换下一轮注额时，上一轮含本金返还、十单净额与累计盈亏均保持原结算口径，避免原稿用新注额重画旧结果的显示问题；下一轮才应用新注额。
- 原单场概率、赔率取整、比分生成、串关全中规则均复用 `sports.ts`。累计虚线用每张实际选单的真实概率乘舍入赔率计算，保留原稿与引擎的精确期望；旁边 92%^k 的说明是名义模型，两者没有混为一项。
- 所有英文整句和队名来自 Sports / common 译文；动态文案按整句模板组织。单复数为 `1 bet` / `1 match`；英文 `Won $…` / `Lost $…` 动词后没有正负号，主盈亏和“本轮”汇总保留带符号净额。金额统一 `money()`，英文注额是 `$1,000`。本页是模拟赌注，按 TRANSLATION 规范中文用元、英文用美元；真实背景销售数据仍用人民币。
- 高亮短语分别指定“最诱人”和 “the most tempting”，英文也能高亮。亏损用 `var(--loss)`，百单还带形状/符号。原稿两个 36px 小按钮提升到至少 44px，英文长标签可换行。

## 原稿口径与待核对项

1. **92% 是本页示例，不是官方竞彩总返奖率。** 原稿另引用官方竞彩 73%，二者保留各自语境。每场赔率四舍五入到 0.01 后，实际期望会略偏离名义 92%；本次累计和虚线继续使用 `evaluate()` 的实际概率 × 赔率，说明/静态图仍为 92%^k。
2. 揭晓的 108.8% / 8.8% 是隐含概率之和与超额，不等于直接亏损 8.8%。原稿正文“约拿回 92 元”属于近似；未改原文字义或把 8.8% 当成结算参数。
3. **原稿的“8 场全押热门，约 0.2%、五百单一中、两三百倍”没有提供具体比赛或实验。** 随机生成的各场真实概率不同，不能保证每一张 8 串 1 都符合这些数。本轮把原示例单独标记 `design_reference`，不冒充新模拟结果。实际每张赔率、中奖与期望都由本轮比赛决定。
4. “知道真实胜率就成了完美预测者”是原文的解释方式，知道概率不等于预知某场结果。真实概率开关只展示概率，不提前揭晓比分或改抽样。显示沿用原稿的整数百分比，三项有时加为 99% 或 101%；底层概率和结算用未舍入值。
5. 原 `makeMatch()` 对平局也消耗一个额外随机数，设计稿脚本只在非平局消耗；本轮直接复用既有引擎，不为追逐设计稿的随机序列改规则。各场分布不变，固定种子生成仍可重现。
6. `Sports.093/094` 的旧 note 写 `Won +` / `Lost −`，按 G-fix 要求英文动词后的金额去掉符号；中文按原稿保留。统一 `money()` 后，原稿静态返还图中的 `92.0` 等金额按站点规则显示为 `92 元` / `$92`，数值与含义不变。
7. 公益/法律/历史销售数据和官方 73% 的当前适用性仍待 D5 核实。本轮未重核法规和外部事实，未改既有 `facts` 或来源描述。原文不是对现行法规核查已经完成的声明。
8. 赌场大厅返回链接已可用；反网赌详情和“如果停不下来”分别指向同语言 `/part2-scam/` 与 `/ending/`，属于后续 G18 / G21。尚未创建这些内容页，也未添加未经核实的热线。
