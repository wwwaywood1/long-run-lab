## 通用规则（和游戏页一样）
1. **数学只写在 `src/engine/`**，并配测试；组件只管状态、计时和画面。
2. **页面上的数字要有出处**：每个任务顺带把本页写死的统计数字接到 `data/numbers.json` 或引擎常量上，并像 `src/views/__tests__/ch1-ev.test.ts` 那样写测试核对文案里的数字。`numbers.json` 缺的数，加进 `research/compute_numbers.py` 再生成（不要手改 json）。
3. 组件放 `src/components/widgets/<名字>.tsx`，替换掉页面里对应的 `data-widget` 块；页面模板在 `src/views/<Page>.astro`（一个模板出中英文，文字用 `t()`，见 `docs/STATIC_PORTING.md`）。
4. 文案：先用本页 `i18n/source/<Page>.json` 里已有的条目。JSON 里缺的界面文字（例如判定结论），在组件顶部写一个 `{ zh, en }` 字典并标 `NEW COPY`，PR 里列出来给 Claude 审定。不要改 JSON 和设计稿。
5. 默认状态要和设计稿一致（下表“默认状态”一栏）；随机模拟用 `src/engine/rng.ts` 的可设种子随机数，测试可复现。
6. 验收沿用 `docs/PORTING.md` 的清单：390/640px、zh/en、无障碍、`npm test`、`npm run build`、`npm run check:en`、浏览器检查脚本 `tools/check_<名字>.mjs`。
