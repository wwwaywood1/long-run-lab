# 设计规范 v0.2（摘要）

完整视觉见 `preview/Main.dc.html` 与各页设计稿。

## 颜色
| 令牌 | 值 | 用途 |
|---|---|---|
| `--page` | #FFFFFF | 页面底色 |
| `--panel` | #F3F4F6 | 面板、分段控件底 |
| `--ink` / `--ink-deep` | #111214 / #0E0F12 | 文字、庄家、全黑揭晓段 |
| `--muted` | #5A606B | 次要文字 |
| `--you` | #2B59C3 | 你、赢 |
| `--loss` | 中文 #15803D / 英文 #D33A35 | 亏损（深色底上用 `--loss-on-dark`） |
| `--highlight` | #FFE066 | 荧光笔：每屏最多一处 |
| `--rule` | #E4E6EA | 分隔线 |

## 字体
展示与大数字：Noto Serif SC 900；正文：Noto Sans SC；数据与标签：IBM Plex Mono。

## 节奏
- 左右边距 24px，内容最大宽 640px。
- 段与段之间 120px；全黑“揭晓”段上下 104px。
- 一个段落只讲一件事：一个问题、一个互动、一个揭晓。

## 每个游戏页的固定结构
1. 标题区：所在位置（赌场大厅 · 编号）、标题、一句话规则。
2. 实验台：控件（同时开 1/10/100、注额、玩法）→ 盈亏大数字与实物换算 → 牌桌 → 按钮（玩一局 / 自动 / 快进 / 重来）→ 盈亏曲线（实线你，虚线期望）→ 每分钟平均输。
3. 全黑揭晓：这张桌子的“0”藏在哪。
4. 白底延伸：赔率、心理机制或真实数据，带出处。
5. 下一张桌子的链接、页脚。

## 无障碍
真按钮（`<button>`），分段控件用 `aria-pressed`，盈亏区域 `aria-live="polite"`，触控目标 ≥ 44px，颜色之外要有文字或形状区分（赢 / 输 / 庄家）。
