## D8 站名：等用户决定

- **中文名同名风险高**：“赌博默示录”是漫画《賭博黙示録カイジ》的通用中文译名，2009 年真人电影也用了这个片名，KAIJI 还是注册商标。读者会误以为是同人或衍生作品，品牌词搜索也会被原作占满。DeepSeek 的首选是“久赌必输”，也就是项目原来的名字。
- **英文名**：DeepSeek 推荐 Ruin Lab、Lose by Design；The Long Run 有商标重名（饮料、化工类），加上 Lab 或 Project 可以避开。The House Always Wins 撞名多，不推荐。
- 这是初筛，不是法律意见。定名之后要查 USPTO、CNIPA 商标和域名。
- 定名最好在发布到 GitHub 之前，因为仓库名也要跟着改。
