# 审稿记录：GPT 的 G1–G4（2026-10-17）

审稿：Claude · 交付：GPT（共享组件 + 骰宝、百家乐、老虎机、爆点，中英文路由）

## 结论：合并，附一张返工单（G-fix）

工程质量好：规则全在引擎里，测试覆盖到边界，计时器和自动模式的收尾处理得干净，每个任务都附了浏览器检查。更难得的是它没有掩盖问题：爆点的两处数学口径、百家乐的洗牌时机、老虎机“差一点”的两种口径，都是它先指出来的，而且都是真问题，责任在设计稿（我）。

主要欠缺在英文：它拿到的是没有译文的 JSON，现在 DeepSeek 的译文已并入，整句都对上了，但被代码拆成碎片的句子拼出来是错的（见第 3 节）。

## 1. 我已经改好的（合并时一起改的）

| 问题 | 处理 |
|---|---|
| **爆点：“3% 起飞即爆”不成立**。生成器先把爆点取整到 0.01，1.00× 的比例变成 1 − 0.97/1.01 ≈ 3.96% | 爆点改成连续值 `max(1, 0.97/(1−u))`，起飞即爆恰好 3%，其余部分恰好公平。倍数只在显示和结算时向下取到 0.01 |
| **爆点：起飞前能在 1.00× 跳车退回本金**，等于躲开了那 3%，“任何手动策略都是 −3%”不成立 | 第一个计时步之前不能跳车（引擎 `canJump`，按钮同步禁用）。手动跳车按屏幕上显示的倍数结算，爆点低于显示倍数才算爆。这样显示值和到手值一致，任何手动策略的期望都恰好是 −3%。新增测试：5 种跳车时机各模拟 4 万局 |
| 爆点显示用 `toFixed(2)` 四舍五入，可能显示 2.00× 却没在 2× 跳成 | 一律向下取整（`floorX`） |
| **老虎机：横幅的“差一点”和揭晓段的“19 倍”不是同一个事件**（横幅要求第三轴相邻格是 7，概率 0.1%；19 倍按前两个 7、第三个不是计算，概率 0.95%） | 统一为“前两个是 7、第三个不是”，与 19 倍同口径，横幅文案改为“前两个都是 7，第三个没停在 7 上”。删掉不再使用的 `p_adjacent_near_miss` |
| **百家乐：剩不到 52 张时会在一局中途洗牌** | 改为每局开始前检查（和赌场切牌一致），加了测试 |
| `sports.ts` 的类型错误（`tsc --noEmit` 报错） | 修好，现在类型检查零错误 |
| 组件只查本页 JSON，`common.json` 里的共用文案（同时开、你的盈亏、重来…）在英文页显示中文 | 新增 `src/i18n/copy.ts` 的 `makeCopy()`，先查本页再查 common，四个组件已换用 |
| 为双色球、刮刮乐、抽卡页准备（G6–G8 用） | `money(…, 'CNY')` 之外，实物换算也支持人民币：`LossConversion` 加 `currency` 参数，英文名称 + 人民币物价 |

| 没有检查英文页残留中文的手段 | 新增 `npm run check:en`：扫描构建结果里英文页的中文 |

## 3. 返工单 G-fix（交给 GPT，做完再开始 G5）

用浏览器把英文页每个模式玩一遍时看到的问题：

1. **碎片拼句**：英文不要把中文碎片的译文拼起来。按每组碎片首条 note 里的 `TEMPLATE:` 在组件里写英文函数。现在能看到的错误有：
   - 爆点：`Chance of cashing out in a round: 48.5%，成功赢 $10，失败输 $10。`
   - 爆点：`还在飞 8 still flying · 0 cashed out · 2`
   - 爆点：`You win +$10 · 它后来crashed at 4.90×`、`Cashed out at 2.00× 跳车`、`2.00× 跳`
   - 老虎机：`You won $5！You put in $10，其实亏了 $5`
   - 百家乐：`Banker赢 · You win`、`Tie局 · bet returned`
2. **实物换算标签**：`输掉的钱 ≈ 2 coffees` 要用 JSON 里带占位符的整句（`Lost so far {{itemText}}`）。
3. **英文里动词后的金额不带正负号**：`You lose −$10` 改为 `You lose $10`，`You win $10` 同理。中文保持设计稿写法。
4. **单复数**：`1 tables`、`1 rounds` 改为单数，英文需要一个按数量选单复数的小函数。
5. **百家乐英文**：路单圆点、百桌格子、揭晓段的连庄圆点放不下 Banker/Player，英文用 B / P / T，图例说明三个字母的含义。
6. **金额格式**：注额按钮 `$1000` 改为 `$1,000`，统一走 `money()`。
7. **页面模板里不要替换中文子串**：比如 `.replace('一分不差', …)`、`.replace('19 倍', …)`、`.replace('3', …)`。英文里匹配不上，高亮会丢；数字变了还会替换错位置。改法：
   - 高亮短语按语言各写一份；
   - 文案里的数字直接用 JSON 原文；
   - 另加一个测试，核对这些文案里的数字和 numbers.json 一致。
8. **百家乐迁到共享组件**：它早于 G1，还在用自己的会话、曲线和分段按钮。改用 `session.ts` 和 `shared/` 组件，删掉重复代码。
9. **验收**：
   - 去掉所有 `TODO(en)`；
   - `npm run check:en` 零残留；
   - 每个 `tools/check_*.mjs` 在英文页玩遍所有模式后，断言页面上没有中文（语言按钮“中”除外）。
